Clothing Color Recognition

A MobileNetV3-Small that predicts a distribution over 13 color categories to discern confidence in each label. 5.85 MB, distilled from a ResNet-50, trained on procedurally generated images.

The models used run locally, so nothing you point the camera at, and nothing you upload, is sent anywhere.

    The latency above times the color model only, measured in this browser
    through WebAssembly, so it is slower than the 6.9 ms the same weights
    reach natively on CPU. Torso detection runs separately and is not counted.
  


  

    Torso detection is MediaPipe Pose (Apache-2.0), not the AGPL pose model the
    Python pipeline uses, so the boxes differ slightly between the two. Its
    weights are served from this page rather than from Google, so no frame and
    no request leaves your machine.
  


  

    Trained on synthetic data only, so it has never seen a real garment. It is
    weakest where two categories meet: pale green against yellow, gray against
    white. The write-up covers why, in detail.
